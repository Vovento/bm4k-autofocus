# BM4K Autofocus

[English](README.md)

Следящий автофокус по лицу и локальный пульт управления для **Blackmagic Pocket Cinema Camera 4K** на macOS.

Камера сама передаёт видеопоток на Mac по USB как веб-камера. BM4K Autofocus анализирует этот поток через Apple Vision, следит за лицом и резкостью и отправляет команды фокуса на камеру по Bluetooth LE. В браузерном пульте есть превью, состояние автофокуса и управление диафрагмой, выдержкой, ISO, балансом белого, записью и уровнем микрофона.

**Приложение не создаёт виртуальную веб-камеру.** В Zoom или другой программе выбирайте саму Pocket Cinema Camera; BM4K Autofocus работает параллельно и управляет объективом. Для слежения и превью он использует один поток Blackmagic. Встроенная камера MacBook, iPhone и обычные карты захвата не выбираются как источник автофокуса.

> **Проверенная связка:** BMPCC 4K + Sigma 18–35 mm f/1.8 Art EF через Metabones Speed Booster 0.64× EF–MFT, macOS. В тестах фокус восстанавливался примерно за 1–1,5 с после остановки движения. С другими объективами и камерами BMPCC 6K работоспособность пока **не проверена**; результаты и доработки приветствуются.

Это неофициальный проект сообщества, не связанный с Blackmagic Design.

## Что умеет

- **Точное слежение:** оценивает расстояние по размеру лица и фокусному расстоянию, выбирает позицию фокуса по профилю объектива, проверяет результат по резкости и уточняет его. Встроенный AF камеры помогает при первоначальном обучении и используется как запасной метод.
- **Запасной режим AF камеры:** если объектив не передаёт расстояние, приложение запускает штатную наводку камеры. Она целится в центр кадра и может не попасть на лицо у края.
- **Локальный пульт:** видеопревью, состояние фокуса и настройки камеры по адресу `127.0.0.1:8765`.
- **Переподключение:** служба повторяет попытки подключения по Bluetooth и открытия USB-видео при отключении и включении камеры.

## Что понадобится

- Mac с macOS, Python 3.9–3.12 и Xcode Command Line Tools (`xcode-select --install`). Закреплённые версии зависимостей пока не проверены на Python 3.13+.
- BMPCC 4K, выдающая изображение по USB как веб-камера, и кабель USB-C с передачей данных.
- Bluetooth на Mac и камере (Menu → Setup → Bluetooth). Отключите телефонное приложение Blackmagic: камера принимает только одно BLE-подключение для управления.
- Объектив с электронным управлением фокусом и, при необходимости, включённым переключателем AF. Точное слежение проверено только с указанной выше Sigma/Metabones связкой.

Код распознаёт названия видеоустройств `Pocket Cinema Camera …` и `Blackmagic … Camera`, но это не означает проверенную совместимость всех моделей.

## Установка

```bash
git clone https://github.com/Vovento/bm4k-autofocus.git
cd bm4k-autofocus
./install.sh
```

Скрипт создаст `.venv`, установит зависимости, соберёт приложение для Dock и фоновую службу, затем предложит включить автозапуск. После установки откройте `BM4K Autofocus.app`. Пульт откроется по адресу [http://127.0.0.1:8765](http://127.0.0.1:8765).

Можно запустить вручную из Terminal: `.venv/bin/python dashboard.py` или двойным кликом по `Запуск пульта.command`. Для просмотра интерфейса без камеры: `.venv/bin/python dashboard.py --sim` при остановленной обычной службе (порт у них общий).

При первом запуске выдайте приложению **BM4K Autofocus Service** доступ к Bluetooth и Камере в «Системные настройки → Конфиденциальность и безопасность». Если камера покажет PIN для сопряжения, введите его на Mac. Журнал службы: `~/Library/Logs/BM4K Autofocus.log`.

Для видеозвонка подключите BMPCC по USB-C, дождитесь связи по Bluetooth и появления видео в пульте, включите следящий AF и выберите **Pocket Cinema Camera** как видеокамеру в Zoom. Картинку в Zoom передаёт сама камера по USB; приложение управляет фокусом по BLE.

## Другие объективы и камеры

В репозитории есть профиль [`profiles/64x-sigma-dc-18-35-1-7-hsm.json`](profiles/64x-sigma-dc-18-35-1-7-hsm.json): измеренная кривая «позиция фокуса → показание расстояния» для Sigma 18–35 через Metabones. Её нельзя без проверки применять к другому объективу. Персональные данные обучения сохраняются отдельно в `focus_model.json` и в Git не публикуются.

С новым объективом точный режим пытается один раз пройти весь диапазон фокуса (около минуты) и записать новый `profiles/<объектив>.json`. В этот момент фокус проходит весь ход. Если объектив не сообщает расстояние, профиль помечается `no_distance`, и приложение использует штатный AF камеры по центру кадра. **На других объективах этот путь не проверен.** Если будете адаптировать проект, пришлите модель камеры, объектива и адаптера, сведения о передаче расстояния, результат съёмки и проверенный профиль в issue или pull request. Не прикладывайте `focus_model.json`, записи трасс и изображения людей.

Поддержка BMPCC 6K — возможное направление развития, а не подтверждённая функция: нужны испытания видеовхода, BLE-команд и обратной связи с реальным железом.

## Если что-то не работает

- **Нет видео:** проверьте USB-C и режим веб-камеры. Приложение не переключается на MacBook/iPhone. Если открытие потока зависло, служба может автоматически перезапуститься; смотрите журнал.
- **Нет связи по Bluetooth:** проверьте Bluetooth с обеих сторон и отключите телефонный контроллер. При устаревшем состоянии перезапустите службу.
- **Нет разрешений macOS:** дайте «BM4K Autofocus Service» доступ к Камере и Bluetooth. После пересборки приложения система может запросить их снова.
- **Порт занят:** проверьте `lsof -nP -iTCP:8765 -sTCP:LISTEN` — возможно, пульт уже запущен.
